# SSH-Log-Analyzer
Beginner project which eventually became my AWS, Serverless log parser.

The primary purpose of this project was two separate goals:
1. Try and build out a simple, beginner friendly project inside of Python
2. Build something which can give me a starting place for any type of log parsing/log analyzation.

While it isn't the first project I have created in Python it is certainly is one which is above some of the other basic things I have created
(calculator, timer, number guesser, etc.). It taught me some pretty cool information, specifically regarding .split() and a basic introduction 
to how a dictionary works!
